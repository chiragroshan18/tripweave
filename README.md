# ✈️ TRIPWEAVE

> **Plan the Journey. Shape the Experience.**

TripWeave is a smart travel itinerary and journey planner web application that helps users discover destinations, create day-by-day travel plans, estimate trip budgets, manage packing checklists, save points of interest, and keep travel journal entries.

---

## 🧭 Core Workflow

```mermaid
flowchart LR
    A[Discover Destinations] --> B[Create Journey]
    B --> C[Build Day-wise Itinerary]
    C --> D[Estimate Budget & Track Packing]
    D --> E[Save Places & Write Journal]
```

---

## 📌 Project Features

- **Destination Discovery**: Browse curated global destinations with recommended stay durations and daily cost estimates.
- **Journey Planner**: Create and manage travel plans with start/end dates, traveler counts, and travel styles (`Culture`, `Nature`, `Luxury`, `Relaxation`, `Adventure`).
- **Day-by-Day Itinerary**: Add and organize daily travel activities with times, venues, categories, durations, and estimated costs.
- **Budget & Expense Summary**: Automatic calculation of total journey cost, daily averages, and category breakdowns.
- **Packing Checklist**: Categorized packing list with progress visualizer and item completion checkmarks.
- **Saved Places Gallery**: Explore and bookmark points of interest, landmarks, beaches, and attractions.
- **Travel Journal**: Log daily travel memories, notes, and highlights.
- **Global Search**: Search across destinations, journeys, activities, and saved attractions.
- **Print Itinerary**: Print-friendly layout for exporting clean physical copies or PDFs.

---

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript, Fetch API
- **Backend**: Python 3, Flask

## 🚀 How to Run

1. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Start Application**:
   ```bash
   python app.py
   ```

3. **Access Application**:
   Open browser at `http://127.0.0.1:5000`
